# Changelog - v0.9.x Series

## v0.9.0 - Utility Scorer MVP

**Release Status:** Complete

### Unified Scoring System
- Designed and refactored utility scoring system
  - Unified UtilityScorer replaces SpellScorer (all candidate types)
  - Scoring formula: `utility = (contextWeight + lambda*learningScore + correlationBonus) * potionMult * favMult`
  - Consolidated into `src/learning/` directory
- UCB exploration bonus implementation (via QLearner integration)

### Correlation-Based Scoring (CorrelationBooster)
- Bow -> arrows, crossbow -> bolts
- Melee + no shield -> defensive items
- Silver weapon + undead target boost

### Potion Usefulness Discriminator (PotionDiscriminator)
- Regeneration potions at combat start (first 30s)
- Flat restore when HP < 30%
- Value ranking by magnitude

### Favorites Boost System (ScorerConfig.favoritesMode)
- Three modes: Boost, Off, Suppress
- Usage-based multiplier (1.3x - 2.5x range)
- Configuration via ScorerConfig

### Other
- WildcardManager migrated from SpellScorer
- Debug widget (UtilityScorerDebugWidget) for score breakdown visualization

### Deferred
- Poison usefulness discriminator (needs testing)
- Food usefulness discriminator (needs survival mode testing)
