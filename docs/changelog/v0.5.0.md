### v0.5.0-alpha
**Initial Alpha Release**

**Features:**
- Context-aware spell recommendation system
- Feature-based contextual bandit learning for player preference modeling
- Wheeler integration for radial menu access
- 17-feature state representation (health, magicka, stamina, combat state, target type, equipment)
- Real-time learning from player spell selections
- Context weight system for situational spell relevance

**Current Limitations:**
- Spell recommendations only (potions/weapons/items planned for beta)
- ImGui widget debug mode only (use Wheeler for release builds)
- Configuration hardcoded (INI support planned)

**Known Issues:**
- Learning system requires 50-100 spell selections to adapt to playstyle
- Some modded spells may need manual classification overrides
