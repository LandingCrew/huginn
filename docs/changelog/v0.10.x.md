# Changelog - v0.10.x Series

## v0.10.0 - Override System

**Release Status:** Complete (Override System); Slot Allocator moved to v0.12.0

### Override System (Safety Overrides)
- Priority-based override injection (post-scoring, pre-widget)
- OverrideManager singleton with `EvaluateOverrides()` and `ApplyOverrides()`
- Override candidates get +1000 utility boost to guarantee top slot
- Consistent behavior across Widget AND Wheeler paths

### Critical Health Override (Priority 100)
- HP < 10% -> Health Potion (Restore, not Fortify)
- Fixed ItemClassifier to distinguish `kValueModifier` (Restore) from `kPeakValueModifier` (Fortify)

### Drowning Override (Priority 50)
- Underwater + no waterbreathing buff -> Waterbreathing Potion

### Weapon Charge Override (Priority 35)
- Enchanted weapon at 0% charge -> Filled Soul Gem
- Added soul gem fill state detection via `ExtraSoul` extraData
- Fixed staff enchantment detection (staves now recognized as enchanted weapons)
- `GetBestSoulGem()` now only returns filled soul gems

### Hysteresis System (Anti-Flicker)
- Activation/deactivation thresholds with configurable hysteresis
- Minimum override duration (default 2 seconds)
- Prevents rapid UI flickering when values hover near thresholds

### Runtime Configuration
- Settings loaded from `Data/SKSE/Plugins/Huginn.ini` [Overrides] section
- Configurable: thresholds, hysteresis values, enable flags, anti-flicker duration
- Settings reload on save load (allows mid-session changes)
