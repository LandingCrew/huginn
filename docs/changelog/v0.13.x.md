## v0.13.0 - Feature Learning & Widget Persistence (2026-02-15)

### Feature-Based Contextual Bandit Learning Migration
- `FeatureQLearner` with 18-float `StateFeatures` vectors
- Linear function approximation: Q(s, item) = w_item · phi(s)
- Gradient descent updates
- External equip learning
- Decay rework (L2 regularization + lazy time-based)
- Cold-start guarantee
- Ring buffer refresh on death fix
- Semi-permanent drains fix

### Scoring Formula Rebalance (v0.12.5-v0.12.6)
- Scoring formula rebalance and context rule consolidation
- State space reduction

### Contextual Bandit Learning Persistence
- SKSE Cosave integration for contextual bandit learning data

### Event-Driven Memory & Equip Event Bus
- Event-driven memory system
- Equip event bus for reward propagation

### Widget Persistence
- **Fixed IntuitionMenu disappearing on cell transitions** — Skyrim closes custom IMenu instances during loading screens without destroying them; added re-show logic in HudVisibilityManager when Loading Menu closes
- **Fixed IntuitionMenu not appearing on new game** — same root cause; the initial Show() from kNewGame was closed by the intro loading screen

### Diagnostics
- Added lifecycle logging to IntuitionMenu (constructor, destructor, Show, Hide, SetVisible)
- Added menu event logging to HudVisibilityManager (tracks which menus trigger visibility changes)
- Added throttled null-singleton warning in update loop
