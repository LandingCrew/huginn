# Huginn v0.12.x Changelog

## Overview: Target Architecture Refactoring Complete

**Status:** ✅ **COMPLETE** (v0.12.5 → v0.12.7)

The "double-scoring problem" identified in February 2026 structural audits has been resolved. Clean architectural separation achieved:
- **ContextRuleEngine:** "What matters RIGHT NOW?" (game state → context weight)
- **PriorCalculator:** "Which item is intrinsically better?" (quality heuristics, context-independent)
- **QLearner:** "What does THIS PLAYER prefer?" (learned preferences)

**Final Formula:**
```cpp
utility = contextWeight × (1 + λ(confidence) × learningScore)
```
Where context is a **gate** (0.0-1.0), learning is a **tiebreaker** within relevant items.

### Critical Thread Safety Fixes (WheelerClient)

Fixed **5 race conditions** (m_pageWheels concurrent access):

| Function | Issue | Fix |
|----------|-------|-----|
| `CreateRecommendationWheels()` | Entire function unprotected | Lock at function start |
| `GetWheelIndexForPage()` | TOCTOU (size check vs [] access) | Lock before size check |
| `FindPageForWheel()` | Unprotected iteration | Lock around loop |
| `UpdatePageWheel()` | Size check before lock | Moved lock UP to line 567 |
| `HandleWheelOpened()` | Unprotected m_pageWheels[0] access | Inlined FindPageForWheel, single lock |

**Lock ordering:** `m_callbackMutex` (outer) → `m_pageDataMutex` (inner) — no deadlock risk.

- Up to 4 pages, 10 slots/page (INI configurable)
